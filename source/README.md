# ImaKuite!Ramen! DEMO（プレゼン用のお試しアプリ）

本物のアプリ（`../imakuite-ramen/`）はそのまま。これはそのコピーに、画面の外（右側）の「デモ用ボタン」を足したものです。

## 起動

```bash
cd imakuite-ramen-demo/app
npm run web
```

`node_modules` は本物のアプリのものを共有（ジャンクション）しています。

## デモ用ボタン（画面右の欄外）

- **新規登録**: 登録フォームから始めます。登録しても、サーバにアカウントは作りません（この端末の中だけ）。
- **ログイン**: ログイン画面から。パスキー／復旧コードのどちらを押しても、三級のお試しユーザーでログインしたことになります。
- **見習い〜特別監察官**: その階級でログイン済みの状態にします（入力項目・他の調査官の評価の黒塗りも、その階級のとおりに変わります）。

## 本物との違い

- 保存先は別（`imakuite_ramen_demo_v1`）。本物のアプリのデータとは混ざりません。
- 登録・ログイン・投稿はすべて端末内。サーバへは送りません。店の一覧だけ、本物と同じ公開データを読み取ります。
- 「他の調査官の評価」は、デモ用の見本データ（実在の評価ではありません）。
- 画面下のビルド表示は `DEMO`。
